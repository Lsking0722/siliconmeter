# SiliconMeter

[English](README.md) · **한국어**

**내 맥 칩이 지금 어떻게 일하고 있는지, 칩 그림 그대로 보여주는 메뉴바 앱**

![SiliconMeter](docs/hero.gif)

애플 키노트에서 새 칩을 소개할 때 나오는 다이 그림 이뻐서 만들었습니다. 성능 코어, 효율 코어, GPU, Neural Engine이 칸칸이 나뉜 그 다이 이미지 맞습니다. 그 그림이 실제로 움직이면 재밌겠다는 생각에서 시작했습니다.

CPU 사용률을 막대그래프나 숫자로 보여주는 앱은 이미 많습니다. SiliconMeter는 같은 정보를 **내 맥에 들어 있는 바로 그 칩의 모양**으로 보여줍니다. 코어 하나하나가 실제 부하만큼 밝아지고, 칩 아래 통합 메모리는 쓰는 만큼 차오르고, Ultra 칩이면 두 다이 사이의 UltraFusion 연결선에 신호가 오갑니다.

---

## 이런 점이 다릅니다

**1. 내 칩 모양 그대로 그립니다**
M1부터 M6, MacBook Neo의 A18 Pro까지 41가지 구성을 지원합니다. 세대마다, 기본·Pro·Max·Ultra마다 블록 배치가 다르고, 가능한 한 Apple이 공개한 칩 일러스트의 배치를 따랐습니다. GPU 코어 수가 적은 비닝 모델(예: 8코어 GPU M3, 30코어 GPU M3 Max)은 꺼진 칸을 어둡게 남겨서, 내 맥이 어떤 모델인지까지 그대로 드러납니다.

**2. 칩마다 색이 다릅니다**
각 칩이 처음 소개될 때의 색을 따왔습니다. M1은 피치에서 블루로, M2는 앰버에서 바이올렛으로, M4는 키노트 다이 사진처럼 라임에서 블루를 거쳐 인디고로 넘어갑니다. A18 Pro는 로즈골드입니다.

**3. 코어 하나하나를 따로 보여줍니다**
"CPU 37%" 같은 평균 하나가 아니라, 코어마다 실제 부하를 받아서 각자 그립니다. 효율 코어만 바쁜지, 성능 코어 하나가 혼자 100%를 찍고 있는지가 한눈에 보입니다. M5 세대의 Super 코어나 M6의 세 등급 구성도 등급별로 나눠 보여줍니다.

**4. Neural Engine 사용량도 잡습니다**
macOS는 Neural Engine 사용률을 직접 알려주지 않고, M4에서는 흔히 쓰는 전력 카운터마저 부하 중에 0으로 나옵니다. 그래서 Neural Engine이 메모리 대역폭을 요청하는 시간 비율로 활동률을 추정하고, 데이터 이동량(GB/s)을 함께 보여줍니다. M4에서 Vision 부하를 걸어 보면 0%에서 90%대까지 올라갑니다. 추정값에는 "(est.)"를 붙였습니다.

**5. 시스템 자원을 안잡아먹게끔 최적화했습니다.**
측정과 애니메이션은 팝업을 열었을 때만 돌아가고, 닫으면 CPU 사용량이 0%입니다. 팝업을 연 동안에도 움직이지 않는 부분(다이 판, 블록 윤곽, 그라디언트, 배선)은 미리 이미지로 그려 두고, 매 프레임에는 변하는 부분만 계산합니다. M4에서 팝업을 열고 30fps로 볼 때 CPU 사용량은 코어 하나의 10~12% 정도입니다.

**6. sudo도, 네트워크도 필요 없습니다**
관리자 권한을 요구하지 않고, 인터넷에 접속하지도 않습니다. 모든 값은 맥 안에서 읽고 맥 안에서 끝납니다.

## 디테일

- **메모리 대역폭:** 메모리 대역폭 칩마다, 용량마다 다른 경우에 그만큼 칩과 메모리 통신하는 선이 더 많아지도록 구현했습니다.
- **코어 위치와 활성도:** 실제 S코어, P코어, E코어 위치에 활성화되는 애니메이션을 통해 내 AP가 얼마나 활성화되어 있는지 보이도록 구현했습니다.
- **네이티브 사용 경험:** 기존 시스템 앱과 같은 느낌이 나도록, 팝업에는 시스템이 그린 Liquid Glass 디자인이 들어가고, 전체적으로 조화로운 배치와 크기 조정 애니메이션을 적용했습니다.

## 기능

- **메뉴바 아이콘:** 칩 이름이 새겨진 작은 칩 모양. 기본 칩은 정사각형, Pro·Max·Ultra는 세로로 긴 사각형에 P·M·U가 표시됩니다. 외장 모니터 같은 일반 해상도(1x) 화면에서는 글자가 뭉개지지 않게 직접 만든 도트 글꼴로 그립니다.
- **팝업:** 왼쪽에는 키노트 스타일의 스펙 목록(코어 등급별 부하, GPU, Neural Engine, 메모리 구성·압박·스왑), 오른쪽에는 실시간 다이 그림. macOS 26 이상에서는 시스템 Liquid Glass 위에 뜨고, 그 이전 버전에서는 어두운 단색 배경을 씁니다.
- **크기 조절:** 다이 크기 100% · 75% · 50%, 그리고 숫자만 크게 보여주는 Simple 모드. 전환할 때 팝업 크기가 부드럽게 바뀝니다.
- **프레임:** 30fps / 60fps 선택. 시스템의 '동작 줄이기' 설정을 따릅니다.
- **손쉬운 사용:** 모든 버튼을 VoiceOver가 읽어 주고, 팝업이 열려 있을 때 ⌘Q로 종료됩니다. '대비 증가'를 켜면 글씨가 더 밝아지고 크기·fps 버튼에 테두리가 생깁니다.
- **로그인 시 자동 실행:** 팝업 아래 체크박스 하나로 켜고 끕니다.

## 어디까지가 실측이고 어디부터가 연출인가

보기 좋게 만들다 보면 어디까지가 진짜 값인지 헷갈리기 쉬워서, 솔직하게 나눠 적어 둡니다.

| 화면에 보이는 것 | 실측 / 연출 | 어디서 읽는지 |
|---|---|---|
| CPU 코어별 부하 | **실측** (코어마다 개별 값) | `host_processor_info` |
| 코어가 어느 클러스터·등급인지 | **실측** | IORegistry `cpuN` 노드, `hw.perflevelN` |
| GPU 사용률 | **실측** (GPU 전체 값 하나, 활성 상태 보기와 같은 값) | IOAccelerator `Device Utilization %` |
| GPU 클럭 | **실측** | IOReport `GPU Stats` |
| GPU 코어별 점등 | **연출**: 전체 사용률을 코어에 나눠 그림 | macOS가 코어별 값을 주지 않음 |
| Neural Engine 활동률 | 칩에 따라 **실측** 또는 **추정 (est.)** | IOReport `SoC Stats`, `PMP`, `AMC Stats`, `Energy Model` |
| 메모리 사용·압박·스왑 | **실측** (활성 상태 보기와 같은 계산) | `host_statistics64`, sysctl |
| 메모리 대역폭 수치 | Apple 공개 사양값 | 칩별 표 |
| 배선 위를 흐르는 펄스 | **연출**: 전체 활동량에 비례한 속도 | 실제 대역폭은 측정하지 않음 |

## 설치

### 내려받아 쓰기

[Releases](../../releases)에서 `SiliconMeter-x.y.z.dmg`를 받아 `응용 프로그램(Applications)` 폴더로 끌어 넣으면 됩니다.

> **처음 열 때 한 번 막힙니다.** 개인 프로젝트라 Apple 공증(notarization)을 받지 않았기 때문입니다. 아래 둘 중 하나로 한 번만 허용하면 그 뒤로는 그냥 열립니다.
>
> - **시스템 설정 → 개인정보 보호 및 보안**으로 가서 "SiliconMeter이(가) 차단되었습니다" 옆의 **그래도 열기**를 누릅니다. (macOS 14 이하는 Finder에서 앱을 우클릭 → **열기**로도 됩니다.)
> - 또는 터미널에서:
>   ```bash
>   xattr -dr com.apple.quarantine /Applications/SiliconMeter.app
>   ```
>
> 받은 파일이 원본인지는 함께 올린 `.sha256` 파일로 확인할 수 있습니다.

### 직접 빌드하기

Xcode 또는 Command Line Tools(`xcode-select --install`)만 있으면 됩니다.

```bash
git clone https://github.com/Lsking0722/siliconmeter.git
cd siliconmeter
./scripts/build_app.sh
open build/SiliconMeter.app
```

직접 빌드한 앱은 위의 '처음 열 때 막힘'이 없습니다.

## 지원하는 칩

| 세대 | 모델 | 칩 그림의 근거 |
|---|---|---|
| M1 | 기본 · Pro · Max · Ultra | Apple 공식 칩 일러스트의 블록 배치 |
| M2 | 기본 · Pro · Max · Ultra | 〃 |
| M3 | 기본 · Pro · Max · Ultra | 공식 일러스트(기본·Max), Pro는 같은 세대 규칙과 다이 비율로 구성 |
| M4 | 기본 · Pro · Max | 공식 일러스트 |
| M5 | 기본 · Pro · Max · Ultra | 공식 일러스트(기본), Pro·Max는 CPU 다이와 GPU 다이를 잇는 구조 |
| M6 | 기본 | 공개 일러스트가 없어 추정 배치 |
| A18 Pro | MacBook Neo | 공식 일러스트 |

비닝 모델까지 합쳐 41가지 구성을 하나씩 확인했습니다. 다만 제가 가진 실기기는 M4 한 대뿐이라, 나머지 칩은 실제 동작 코드를 그대로 쓰되 칩 정보와 부하만 가상으로 넣는 디버그 모드로 검수했습니다. 다른 칩을 쓰시는데 배치가 이상하게 나온다면 이슈로 알려주세요. 아래 진단 출력을 같이 붙여 주시면 바로 고칠 수 있습니다.

```bash
/Applications/SiliconMeter.app/Contents/MacOS/SiliconMeter --dump
```

## 알려진 한계

- **GPU는 코어별 값을 알 수 없습니다.** macOS가 GPU 전체 사용률만 알려주기 때문에, 코어별 점등은 그 값을 나눠 그린 연출입니다.
- **Neural Engine 값은 칩에 따라 추정치입니다.** 특히 M4 이후 칩은 "(est.)" 표시가 붙습니다.
- **비공개 API(IOReport)를 씁니다.** 그래서 Mac App Store에는 올릴 수 없고, macOS 업데이트로 일부 값이 안 나오게 될 수 있습니다. 그럴 땐 해당 항목이 "Not reported"로 표시되고 앱은 계속 동작합니다.
- **macOS 13에서는 직접 돌려 보지 못했습니다.** macOS 13을 대상으로 빌드되므로 13에 없는 기능은 빌드 단계에서 걸러지지만, 실기기 확인은 아직입니다.
- **M6 칩 배치는 추정입니다.** 공식 일러스트가 나오면 맞춰 고칠 예정입니다.

## 만든 방식에 대해

SwiftUI로 그렸고, 외부 라이브러리 없이 Swift Package 하나로 빌드됩니다. 데이터를 읽는 부분은 [SiliconScope](https://github.com/kennss/SiliconScope)(MIT)의 검증된 방식을 참고했고, M5 세대 코어 등급 규칙은 [Stats](https://github.com/exelban/stats)를 참고했습니다. 자세한 고지는 `THIRD_PARTY_NOTICES.md`에 있습니다.

다이 그림의 큰 블록 배치는 Apple 일러스트를 참고했지만, 블록 안쪽의 세부 선과 애니메이션은 직접 그린 것이고 Apple 로고는 넣지 않았습니다.

측정 방식, 칩별 배치 근거, 디버그 모드와 진단 명령은 [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md)(영문)에 정리해 두었습니다.
